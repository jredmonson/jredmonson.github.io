- The editable source file (AI, EPS, or SVG) is the single most important deliverable - without it, you can't resize, recolor, or edit your logo without paying someone to recreate it.
- A JPEG or PNG alone is not a complete handover; those are output files, not source files.
- Brand guidelines should specify exact color codes (hex, RGB, CMYK), approved fonts, spacing rules, and minimum size requirements.
- Ask for the full file package and guidelines in writing before you pay the final invoice, not after.

Logo source files and brand guidelines are what actually make a logo yours. A finished logo image is the visible result of a design project, but the source files are the raw material - the layered, editable version that lets you or anyone else make changes later without starting from scratch. If a designer only hands you a JPEG at the end of a project, you technically have a picture of your logo, not ownership of your logo.

This matters more than most business owners realize until they try to update a sign, resize a logo for a new app icon, or switch to a different printer who asks for a vector file. ## What Counts as a Proper Logo Source File

A proper logo source file is a vector-based, layered document - typically an Adobe Illustrator (.AI) or Encapsulated PostScript (.EPS) file - that can be opened, edited, resized infinitely without quality loss, and exported into any other format needed later. A JPEG or PNG is an output, not a source.

Vector files store the logo as mathematical paths rather than pixels, which is why they can be blown up to billboard size or shrunk to a favicon without going blurry. Anyone asking for print work, embroidery, signage, or merchandise will ask for this file first.

| File Type | Editable? | Scalable Without Quality Loss? | Common Use |
|---|---|---|---|
| .AI / .EPS | Yes | Yes | Master source, printers, future edits |
| .SVG | Yes (code-level) | Yes | Websites, apps |
| .PDF (vector) | Sometimes | Yes | Sharing with vendors |
| .PNG (transparent) | No | No | Web use, presentations |
| .JPG | No | No | Basic web/social use only |

If the only files you have sit in the bottom two rows of that table, you don't have a complete deliverable yet.

## The Full File Package You Should Receive

A complete logo handover includes the master vector file, a print-ready PDF, transparent PNGs in multiple sizes, a black-and-white or single-color version, and a favicon-ready square version. Each format serves a different real-world use case, and missing even one causes friction later.

- **Master vector file (.AI or .EPS)** - the editable original
- **Print-ready PDF** - for anyone who doesn't have design software but needs high-res output
- **Transparent PNG (large and small)** - for websites, presentations, overlays
- **Black-and-white / single-color version** - for stamps, engraving, fax cover sheets, low-cost printing
- **Square/icon version** - for social media profile images and app icons
- **SVG file** - for web developers who need a lightweight, scalable web asset

Missing any of these isn't a minor inconvenience. It's the reason business owners end up paying a second designer just to "extract" a usable file from a locked PNG.

## What Brand Guidelines Should Actually Cover

Brand guidelines should document exact color codes, approved fonts, logo spacing rules, minimum size restrictions, and examples of misuse. Without this document, every future person who touches your brand - a new employee, a print shop, a web developer - will guess at the details, and the guesses won't match.

A usable brand guidelines document, even a simple one-page version, should include:

| Element | What to Specify |
|---|---|
| Primary colors | Hex, RGB, and CMYK codes |
| Secondary/accent colors | Same code format |
| Approved fonts | Font names + where to license/download |
| Clear space | Minimum padding around the logo |
| Minimum size | Smallest size before legibility breaks |
| Do-not-do examples | Stretching, recoloring, rotating, adding effects |

The "do-not-do" section is the one most guidelines skip, and it's often the most useful part - it prevents a well-meaning employee from stretching the logo to fit a banner and quietly damaging brand consistency.

## Why a JPEG-Only Handover Is a Red Flag

A designer who only delivers a JPEG or low-res PNG at project completion is either withholding the source file intentionally or never built one properly in vector software. Either way, it puts you in a position where you can't make changes without paying someone - possibly the same designer - again.

This comes up most often with:

- Cheap logo marketplaces that generate a design from a template and never build a true vector original
- Freelancers who design directly in Photoshop instead of Illustrator, meaning no true vector file ever existed
- Agencies that intentionally withhold source files as leverage to keep you as a client

Ask directly, before hiring: "Will I receive the editable vector source file and a written brand guide at project completion?" A confident yes with no hesitation is what you want to hear.

## How to Request a File Handover If You Never Got One

If you already have a logo but never received the source files, contact the original designer or platform and request the master file in writing, referencing the original invoice or project agreement. If that fails, a designer can often recreate a vector version from a high-res image, though this adds cost and time.

Steps to recover or rebuild your file set:

1. Check old project folders, email attachments, and any project management tool used during the original design (Basecamp, Trello, Google Drive links)
2. Email the original designer directly and ask specifically for the .AI or .EPS file
3. If unresponsive or the business closed, hire a designer to vectorize your existing high-res logo
4. Build a one-page brand guide from scratch using your current color usage as the baseline, even if no formal guide ever existed

This is a common repair job, not a rare one - plenty of small business owners are running on a logo they can't actually edit.

## Who Should Keep the Files and Where

The business owner - not the designer, not the agency - should have permanent access to the full file package, stored somewhere outside the designer's own system, such as a shared cloud folder the business controls. Relying solely on the designer's storage means losing access if that relationship ends.

A simple storage setup:

- One folder in a cloud drive you own (Google Drive, Dropbox)
- Subfolders for: Master Files, Web/Social Files, Print Files, Brand Guidelines
- A copy shared with anyone doing ongoing marketing work (printer, web developer, social media manager)

## FAQ

**Q: What file format is considered the true source file for a logo?**
A: An .AI (Adobe Illustrator) or .EPS file is considered the true source file because it's vector-based and fully editable. PNG and JPG files are outputs generated from the source, not the source itself, and can't be edited or infinitely resized.

**Q: Can I ask for source files after the project has already been paid and closed?**
A: Yes. You can request them anytime by referencing the original invoice or agreement, though some designers charge a retrieval or recreation fee if significant time has passed or the files weren't properly archived.

**Q: Do I really need brand guidelines if I'm a small local business?**
A: Yes, even a one-page version helps. It keeps your colors and fonts consistent across your website, signage, business cards, and social media, and it saves time whenever you hire a new printer, designer, or marketer.

**Q: What if my current logo only exists as a low-resolution JPEG?**
A: A designer can vectorize it - essentially redraw it as an editable file based on the existing image. It's not free, but it's a one-time fix that gives you a proper source file going forward.
